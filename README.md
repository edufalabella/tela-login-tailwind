# 🖥️ Tela de Login com TailwindCSS

Este projeto consiste em uma **tela de login responsiva** desenvolvida com **HTML + TailwindCSS**, com foco em praticar conceitos de estilização moderna e responsiva.

---

## 🚀 Tecnologias Utilizadas
- **HTML5**
- **TailwindCSS (via CDN)**
- **Responsividade com Flexbox**
